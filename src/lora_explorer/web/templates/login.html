Locked out?

Run this command on your host machine to reset authentication:

Docker:

docker exec lora-the-explorer python -m lora_explorer.reset_password

Bare metal:

python -m lora_explorer.reset_password --data-dir /path/to/data

Use --mode password, --mode oidc, or --mode all (default) to choose what to reset.
